# Plotting scripts

The reusable ACWF plotting scripts are deposited under `scripts/acwf-verification/upstream/3-analyze/outputs/`. They provide the equation-of-state diagnostic plotting machinery used by the verification workflow.

The UZH-specific publication figures are deposited under `figures/` and `manuscript/`. The tabular epsilon values used to construct periodic-table maps can be regenerated with `scripts/epsilon/compute_uzh_epsilon_tables.py`.
